# Задача о каннибалах (ИДЗ №1, вариант 6)

Последовательная имитационная программа на C для Linux: дикари едят из общего горшка, повар наполняет его, когда он пустеет.
Курс «Архитектура компьютера и операционные системы», НИУ ВШЭ.

## Сборка и запуск
```
make
./cannibals -n 5 -c 4 -m 3 -t 1:6 -k 3:8 -r 42 -d 100
./cannibals -h      # все опции
./cannibals         # интерактивный ввод параметров
```

## Опции
| Опция | Значение |
|---|---|
| `-n N` | количество дикарей |
| `-c M` | вместимость горшка |
| `-m K` | приёмов пищи у каждого (0 = бесконечно, остановка Ctrl+C) |
| `-t MIN:MAX` | интервал между приёмами пищи |
| `-k MIN:MAX` | длительность приготовления |
| `-s S` | общий запас порций (0 = не ограничен) |
| `-r SEED` | seed генератора случайных чисел |
| `-d MS` | реальная задержка на единицу виртуального времени |
| `-l FILE` | файл журнала (по умолчанию `cannibals.log`) |

## Тесты
