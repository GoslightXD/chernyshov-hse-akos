# Задача о каннибалах, клиент-сервер по TCP (ИДЗ №4, вариант 6)

Сервер хранит состояние горшка. Повар, каждый дикарь и наблюдатели - отдельные клиенты, подключаются по TCP.

| Программа | Роль |
|---|---|
| `cannibals_server` | горшок: состояние, очередь ожидающих, учёт клиентов, итог |
| `cannibals_cook` | повар |
| `cannibals_savage -i ID` | дикарь с номером `ID` |
| `cannibals_observer` | наблюдатель: показывает все события системы (их может быть много) |

## Сборка
```
make
```

## Запуск на одном компьютере
Вручную, каждый в своём терминале (порядок любой, клиенты ждут сервер до 10 секунд):
```
./cannibals_server -p 5555 -n 3 -c 2 -m 2
./cannibals_cook -p 5555
./cannibals_savage -p 5555 -i 1
./cannibals_savage -p 5555 -i 2
./cannibals_savage -p 5555 -i 3
./cannibals_observer -p 5555
```
Или одним скриптом:
```
./scripts/run_local.sh -n 3 -c 2 -m 2 -p 5555
```

## Запуск на нескольких компьютерах
Сервер слушает все интерфейсы, клиенты указывают его адрес:
```
# компьютер A (192.168.1.10)
./cannibals_server -a 0.0.0.0 -p 5555 -n 5 -c 4 -m 3

# компьютеры B, C, D
./cannibals_cook -a 192.168.1.10 -p 5555
./cannibals_savage -a 192.168.1.10 -p 5555 -i 3
./cannibals_observer -a 192.168.1.10 -p 5555
```
Порт должен быть открыт в файрволе сервера.

## Опции
Сервер:

| Опция | Значение |
|---|---|
| `-a ADDR` | адрес, на котором слушать (по умолчанию `0.0.0.0`) |
| `-p PORT` | порт (по умолчанию 5555) |
| `-n N` | дикарей (1..100) |
| `-c M` | вместимость горшка |
| `-m K` | приёмов пищи у каждого (0 = бесконечно) |
| `-t MIN:MAX` | пауза между приёмами пищи, мс |
| `-k MIN:MAX` | длительность приготовления, мс |
| `-s S` | запас порций (0 = не ограничен) |
| `-r SEED` | seed генератора |
| `-l FILE` | журнал сервера (по умолчанию `cannibals.log`) |
| `-i` | интерактивный ввод параметров |

Клиенты: `-a ADDR` (по умолчанию `127.0.0.1`), `-p PORT`, `-w СЕК` (сколько пытаться подключиться, по умолчанию 10), `-l FILE`, у дикаря ещё `-i ID`. Параметры модели клиенты получают от сервера.

## Подключение и отключение клиентов
- Наблюдателей можно подключать и отключать в любой момент, при подключении они получают снимок состояния и последние события.
- Дикаря можно отключить (`Ctrl+C`) и запустить снова с тем же `-i`: сервер помнит, сколько порций он съел.
- Повара можно отключить во время приготовления: невыполненный запрос остаётся, новый повар сразу его выполнит.
- Останов сервера (`Ctrl+C` или `SIGTERM`) корректно завершает всех клиентов. Если сервер убит аварийно, клиенты завершаются с кодом 1 и сообщением о потере соединения.
- `SIGUSR1` серверу выводит текущее состояние.

## Файлы
- `common.c/h` - параметры сервера, вывод, журнал, время, сигналы
- `net.c/h` - сокеты, чтение строк, разбор параметров клиентов, рукопожатие, описание протокола
- `server.c`, `cook.c`, `savage.c`, `observer.c` - программы
- `scripts/run_local.sh` - запуск всех на одном компьютере
- `tests/run_tests.sh` - тесты
- `report.md` - отчёт
