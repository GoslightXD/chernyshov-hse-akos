# Задача о каннибалах, многопоточная версия (ИДЗ №2, вариант 6)

Повар и каждый дикарь - отдельные потоки pthread. Две программы с общим кодом модели:

| Программа | Синхронизация |
|---|---|
| `cannibals_sem` | мьютекс + семафоры |
| `cannibals_cond` | мьютекс + условные переменные |

## Сборка
```
make                 # обе программы
make tsan            # то же с ThreadSanitizer
```

## Запуск
```
./cannibals_sem -n 5 -c 4 -m 3 -t 300:1200 -k 500:1500 -r 42
./cannibals_cond -h
./cannibals_sem
```

| Опция | Значение |
|---|---|
| `-n N` | дикарей |
| `-c M` | вместимость горшка |
| `-m K` | приёмов пищи у каждого (0 = бесконечно) |
| `-t MIN:MAX` | пауза между приёмами пищи, мс |
| `-k MIN:MAX` | длительность приготовления, мс |
| `-s S` | запас порций (0 = не ограничен) |
| `-r SEED` | seed генератора |
| `-l FILE` | журнал (по умолчанию `cannibals.log`) |
| `-i` | интерактивный ввод |

Сигналы: `SIGINT`/`SIGTERM` - корректная остановка со статистикой, `SIGUSR1` - вывести текущее состояние, повторный `SIGINT` - немедленный выход.

## Файлы
- `common.c/h` - параметры, ввод-вывод, журнал, время, генератор
- `core.c` - модель: потоки дикарей и повара, инварианты, сигналы, статистика
- `sync.h`, `sync_sem.c`, `sync_cond.c` - блокировка и пробуждение потоков
- `main.c` - точка входа
- `tests/run_tests.sh` - тесты
- `report.md` - отчёт
