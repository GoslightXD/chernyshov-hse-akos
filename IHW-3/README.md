# Задача о каннибалах, взаимодействующие процессы (ИДЗ №3, вариант 6)

Повар и каждый дикарь - отдельные процессы. Четыре реализации:

| Реализация | Процессы | Семафоры | Данные |
|---|---|---|---|
| `cannibals_fork_named` | родитель делает `fork` | именованные POSIX | разделяемая память POSIX |
| `cannibals_fork_unnamed` | родитель делает `fork` | неименованные POSIX в разделяемой памяти | разделяемая память POSIX |
| `cannibals_host` + `cannibals_cook` + `cannibals_savage ID` | независимые программы | именованные POSIX | разделяемая память POSIX |
| `cannibals_mq_host` + `cannibals_mq_cook` + `cannibals_mq_savage ID` | независимые программы | именованные POSIX | очереди сообщений POSIX |

## Сборка
```
make
```

## Запуск
Единый запуск с `fork`:
```
./cannibals_fork_named -n 5 -c 4 -m 3 -t 300:1200 -k 500:1500 -r 42
./cannibals_fork_unnamed -h
```
Независимые программы, одним скриптом (хозяин, повар и дикари запускаются как отдельные процессы):
```
./scripts/run_independent.sh shm -n 5 -c 4 -m 3
./scripts/run_independent.sh mq  -n 5 -c 4 -m 3
```
То же вручную, в разных терминалах (порядок любой, кроме того, что хозяин должен быть запущен):
```
./cannibals_host -n 3 -c 2 -m 2          # терминал 1
./cannibals_cook                         # терминал 2
./cannibals_savage 1                     # терминалы 3-5: дикари 1, 2, 3
```
Параметры задаёт только хозяин, остальные процессы читают их у него.

| Опция | Значение |
|---|---|
| `-n N` | дикарей (1..100) |
| `-c M` | вместимость горшка |
| `-m K` | приёмов пищи у каждого (0 = бесконечно) |
| `-t MIN:MAX` | пауза между приёмами пищи, мс |
| `-k MIN:MAX` | длительность приготовления, мс |
| `-s S` | запас порций (0 = не ограничен) |
| `-r SEED` | seed генератора |
| `-l FILE` | журнал (по умолчанию `cannibals.log`) |
| `-i` | интерактивный ввод |

Сигналы (хозяину или родителю): `SIGINT`/`SIGTERM` - корректная остановка, `SIGUSR1` - вывести состояние, повторный `SIGINT` - немедленный выход. При любом завершении семафоры, разделяемая память и очереди удаляются.

## Файлы
- `common.c/h` - параметры, вывод, журнал, время, сигналы
- `shm.h`, `core_shm.c` - модель на разделяемой памяти (общая для трёх первых реализаций)
- `sync_named.c`, `sync_unnamed.c` - блокировка и пробуждение на именованных и неименованных семафорах
- `fork_main.c` - родитель с `fork`
- `ind_host.c`, `ind_cook.c`, `ind_savage.c` - независимые программы на разделяемой памяти
- `mq_proto.h`, `mq_host.c`, `mq_cook.c`, `mq_savage.c` - независимые программы на очередях сообщений
- `scripts/run_independent.sh` - запуск независимых программ
- `tests/run_tests.sh` - тесты (`./tests/run_tests.sh fork_named ind_mq` - только выбранные варианты)
- `report.md` - отчёт
